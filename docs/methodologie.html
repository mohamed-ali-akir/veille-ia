Méthodologie

Comment cette veille est construite, de la collecte des articles jusqu'à leur affichage.

Objectif

Suivre l'actualité de l'intelligence artificielle du point de vue d'un développeur (BTS SIO option SLAM) : nouveaux modèles, outils de programmation assistée, agents, open source, sécurité et régulation.

La veille doit permettre de retrouver n'importe quel article en moins de 30 secondes, grâce à une recherche instantanée et à des filtres.

Fonctionnement

GitHub Actions : lancé automatiquement deux fois par jour
1. Récupérer collecte.py Lit les flux RSS des sources (articles de moins de 30 jours).
→
2. Trier tri.py Filtre par mots-clés, puis l'IA résume, classe et note.
→
3. Stocker data/veille.db Base SQLite. L'URL unique empêche les doublons.
→
4. Publier generer_site.py Exporte les articles en JSON pour ce site, alerte Discord pour les 4★ et 5★.

Les chiffres de la veille

Chaque étape élimine les articles hors sujet ou peu utiles :

–articles collectés
–gardés par les mots-clés
–analysés par l'IA
–jugés pertinents et affichés

1. Les sources

Les articles viennent de flux RSS : un format standard que la plupart des sites d'actualité proposent. Les sources mélangent actualité française et anglaise, blogs officiels des éditeurs d'IA, sites pour développeurs et communautés. La liste se modifie dans le fichier sources.yml, sans toucher au code.

SourceCatégorieArticles affichés

2. Le tri en deux temps

  1. Filtre par mots-clés (mots_cles.yml) : rapide et gratuit. Un article qui ne contient aucun mot lié à l'IA est écarté. Les sigles comme « AI » sont cherchés en majuscules pour ne pas confondre avec « j'ai ».
  2. Analyse par une IA (API Google Gemini, offre gratuite) : pour chaque article gardé, l'IA écrit un résumé en français, choisit 1 à 3 tags dans une liste fixe et donne une note de pertinence de 0 à 5. La réponse est vérifiée par le programme avant d'être enregistrée : tags inconnus supprimés, note ramenée entre 0 et 5.

3. Le stockage

Les articles sont enregistrés dans une base SQLite (un simple fichier). L'adresse de chaque article est déclarée UNIQUE : un article déjà connu est ignoré, donc il n'y a jamais de doublon. Toutes les requêtes SQL sont paramétrées, ce qui protège contre l'injection SQL.

4. La diffusion

  • Ce site est statique (HTML, CSS et JavaScript sans framework), hébergé gratuitement par GitHub Pages. Il lit le fichier articles.json et filtre les articles directement dans le navigateur.
  • Discord : les articles notés 4 ou 5 sont envoyés automatiquement dans un salon grâce à un webhook.

Fréquence

Un workflow GitHub Actions lance toute la chaîne deux fois par jour (matin et soir), puis enregistre la base et le site mis à jour dans le dépôt. Il peut aussi être lancé à la main (bouton « Run workflow »).

Limites et esprit critique

  • Les résumés et les notes sont produits par une IA : ils peuvent contenir des erreurs. Le lien vers l'article d'origine est toujours fourni pour vérifier.
  • L'offre gratuite de l'API limite le nombre d'analyses par jour : les articles en trop sont analysés au lancement suivant.
  • La majorité des sources sont anglophones : c'est là que l'actualité de l'IA sort en premier. Les résumés sont en français pour faciliter la lecture.
  • Les flux RSS ne donnent qu'un extrait de l'article : l'IA juge à partir du titre et de cet extrait, pas du texte complet.

Technologies

Python 3 (feedparser, PyYAML, sqlite3, urllib), SQLite, API Gemini, HTML / CSS / JavaScript, GitHub Actions, GitHub Pages, webhook Discord. Tout est gratuit.
